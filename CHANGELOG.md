# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1] - 2026-06-10

### Added

- CSS formatting through Visual Studio's `Edit.FormatDocument` command.
- Visual Studio ProgID and formatting timeout settings.
- Visual Studio Marketplace packaging and publishing workflow.
- Vitest unit test suite with coverage thresholds.
- VS Code Marketplace `Formatters` category validation.
- Zero-configuration default CSS formatter registration.
